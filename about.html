MAIDA ESPORTS
Tournament Management System

Sistem pengurusan tournament PUBG Mobile berasaskan web — satu platform untuk urus data perlawanan, kira mata (standing), dan hasilkan overlay siaran langsung (OBS) secara automatik. Dibina sepenuhnya guna HTML/CSS/JavaScript, disimpan di GitHub Pages, dan disegerakkan melalui localStorage + Firebase.

PUBG Mobile Live Tournament OBS Ready · 1920×1080 Firebase Sync Zero Backend

📋 Ringkasan Sistem

Bagaimana semuanya berhubung kait.

Standing Point ialah otak sistem (master data). Semua placement & kill dimasukkan di sini, kemudian di-LOCK setiap map. Data yang disahkan mengalir automatik ke Leaderboard (dashboard live) dan ke semua overlay OBS (Popup Kill, WWCD, Overall/Map Standing). Penonton pula boleh lihat keputusan melalui Public Results.

💡 Konsep utama: 1 sumber kebenaran (Standing Point) → banyak paparan (Leaderboard + Overlay + Public). Kemas kini sekali, semua ikut.

📊 Tab Standing Point

4 tab dalam fail master.

  • STANDING — Map Standing (susun placement, isi kill setiap map, LOCK/UNLOCK) & Overall Standing (kumulatif semua map locked). Ada PRINT SEMUA (map + overall sekali cetak).
  • HAVOR — Analisis statistik: jumlah team, maps locked, total kills, WWCD, top score, best kill, Kill MVP, avg/map + Kill Leaderboard + WWCD & Placement.
  • MEDSOS — Overlay OBS (Overall / Map Standing) 1920×1080. Pilih PAPAR: OVERALL atau map tertentu, tekan BUKA TAB BARU untuk OBS.
  • SETTING — Map Config (tambah/edit/padam map) & Team Management (tambah team, upload logo & banner via URL, kad bernombor) & Data Management (Save/Export/Import/Reset).

🎮 Aliran Kerja Crew

Peranan CREW 1 · Standing dan CREW 2 · Broadcast.

Sebelum EventCrew 1 buka Standing Point → SETTING: daftar semua pasukan (nama, logo, banner) & setup map (Map Config).
Semasa Game CREW 2Crew 2 buka Leaderboard — kemas kini ELIMS (setiap kill = +1 ELIMS & +1 PTS) & status alive pasukan secara langsung untuk OBS.
Selepas Game CREW 1Crew 1 buka Standing Point → STANDING — susun placement, isi kill, kemudian LOCK. Data disahkan & auto-sync ke Leaderboard + semua overlay.
Game Baharu CREW 2Crew 2 tekan RESET di Leaderboard — ELIMS kembali 0, PTS kekal. Ulang untuk game seterusnya.
Paparan SiaranOverlay (Overall Standing, Popup Kill, WWCD) auto-update setiap 2 saat mengikut data terkini.

🖥 Cara Setup OBS

Buka Modul OverlayDari Home, klik modul OBS (cth Overall Standing atau Popup Kill) → tekan BUKA TAB BARU.
Tambah Sumber di OBSOBS → Add → Window Capture (atau Browser Source untuk link) → pilih tetingkap yang dibuka.
Saiz & Auto-updateOverlay standing = 1920×1080. Popup Kill = green-screen (guna Chroma Key). Semua auto-update 2 saat.
🎯 Tip: Popup Kill guna latar hijau — tambah filter Chroma Key di OBS untuk buang latar. Overlay standing guna latar gelap penuh (window capture terus).
